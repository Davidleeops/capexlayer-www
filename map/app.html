This explorer reads data.json next to it. Generate it with:

make graphify-explorer  (offline snapshot)
or
make graphify-explorer src=supabase  (live)

Then refresh. If you opened this as a file, serve the folder first so it can load the data:
python3 -m http.server 8765 --directory dashboard/explorer then open http://localhost:8765/
